# Contributing to VisionTechOS

Thanks for your interest in contributing!

## How to Contribute

1. Fork the repo
2. Create a branch: `git checkout -b feature/your-feature`
3. Make your changes and commit
4. Push to your fork and open a Pull Request

## Areas to Help With

- **Installer** — improve the guided setup experience
- **Desktop** — UI polish, theming, default apps
- **Base system** — package selection, boot performance
- **Docs** — guides, screenshots, translations
- **Testing** — test on real hardware and report issues

## Code Style

- Shell scripts: POSIX-compatible where possible
- Keep it fast and lean — avoid bloat

## Reporting Issues

Open an issue with your hardware specs, what you expected, and what happened.
